# 灵息 BreathOn

**面向医药代表的学术沟通练习与复盘工具。**

BreathOn 将资料学习、模拟医生对话、练习复盘和拜访记录连接起来，帮助代表在拜访前准备问题与证据，在练习中调整表达，在拜访后整理观察。代表使用 Android App，培训与内容管理人员通过 Web 后台维护资料和审核内容。

## 一次练习，如何帮助下一次拜访

1. **先准备**：学习产品与疾病相关课程，查看模拟医生的专业背景和关注点，明确本次想练习的问题。
2. **开口练习**：选择医生角色、练习重点和演练方式，通过语音完成一轮模拟拜访。
3. **回看原话**：对照对话转录与教练反馈，识别没有答清的问题、需要补充的证据和可以改进的表达。
4. **继续改进**：安排下一次练习，记录真实拜访后的观察；经核对和审核的内容可用于后续训练。

## 为谁提供帮助

| 使用者 | 可以做什么 |
| --- | --- |
| 医药代表 | 学习课程、模拟拜访、查看个人复盘、记录拜访日记 |
| 培训与内容管理人员 | 维护训练课程与场景，查看代表记录，整理可复用的经验案例 |
| 医学与合规审核人员 | 核对资料来源与适用范围，按职责审核指定内容版本 |

医生 IP 是用于演练的模拟角色。公开专业背景与训练设定分开呈现，不代表真实医生本人或其私有偏好。

## 在 App 中学习、练习与复盘

**两种语音演练方式。** 辅助练习中，模拟医生以语音和文字回应，教练在对话中提供建议；实战练习中，双方进行可打断的语音交流，结束后统一复盘。

**从原话出发的反馈。** 练习记录保留转录和教练反馈，便于回看具体表达。绑定有效评分场景的记录可结合量表、资料引用和人工点评复盘，并建立同版本重练；自由练习不提供场景量表分数。

**有进度的学习。** L1–L4 课程覆盖产品、疾病、医生沟通和模拟拜访。代表可以加入个人训练计划、标记完成，并查看实际学习进度。

**保存拜访后的观察。** 拜访日记支持文字记录和已获授权的录音。转写内容经人工核对、脱敏和审核后，才可进入共享训练。

App 的四个入口为「首页、训练、教练、我的」，练习记录和拜访日记集中在「我的」。

## 在管理后台维护内容与审核

Web 后台提供总览、药品、医生 IP、用户画像、政策、训练内容、审核队列、代表记录和系统设置。

- **资料有来源**：管理药品、医生、政策和训练资料；公开资料检索结果先形成草稿，核对后再发布。
- **发布有版本**：课程与训练内容按版本维护，可配置管理员审核、双人审核或医学与合规分别审核。
- **进度有依据**：总览和训练指标读取工作区实际数据；缺少数据时保留空值。
- **共享有授权**：手动健康观察先保存为个人记录，经本人逐条授权、管理员审核后才向代表共享，授权可撤回。当前未接入项链或其他设备。

## 开始使用

**代表端：** 安装 Android APK，使用管理员提供的账号登录，从「教练」开始练习。当前 App 的练习药品范围为已发布玛仕度肽，支持医生 IP 与练习重点选择；详细步骤见[使用手册](docs/user-manual.md)。

**管理端：** 使用管理员账号进入已部署服务的 `/admin`，准备课程、资料与审核规则，操作见[管理后台说明](docs/admin-management.md)。

账号由管理员配置，不提供公开注册。App 的登录、资料读取和语音演练需要联网；升级页面需安装新版 APK。安装与构建说明见[Android 指南](docs/android.md)。

## 数据与使用边界

个人演练和拜访记录按账号隔离；管理员可按权限查看并留下访问审计。语音及相关文本会发送给配置的语音、模型服务，请只使用已获授权的内容，不要输入真实患者身份信息。

AI 反馈用于练习参考，医学内容需要专业复核。资料可追溯不等于医学结论已获确认；学习进度和练习分数不代表能力认证。健康观察为探索性记录，不作为诊断或疗效依据。
