# 医药代表推广合规

用于学术推广训练与风险筛查。发现问题时指向具体言行和需要改变的动作，不把沟通欠佳一律定性为违法，也不把缺少材料视为已经违规。

## 适用依据

核对日期：2026-10-27，适用地区：中国大陆。依据2026年第42号公告《医药代表管理办法》及官方政策解读；该办法自2026-08-01施行。疑似不良反应处理另参照持有人的药物警戒流程。关键条款、原文与转载的区别见 [来源与适用边界](references/sources.md)。

据此训练一般行为边界；若要判断某次现实入院、备案资格、报告时限或活动是否合法，核对当时有效法规、机构接待要求、持有人授权与公司制度。只有旧材料或无法核对时标记待核实，不能承诺合法。不把大陆规则直接套用于港澳台或医疗器械岗位。

## 按实际言行识别

| 线索 | 训练中的处理 |
| --- | --- |
| 未备案、未登记、未获机构同意，或超出授权范围推广 | 先核实条件与接待安排；不教绕过门禁、跟进诊室、伪装身份或以私人接触规避流程 |
| 处方量返利、购物卡、私人旅游等利益安排；以学术名义包装交换 | 停止该交换，不能靠换措辞合规化；改为提交真实医学问题、核对材料或按制度申请学术活动，仍需实际审核 |
| 让代表背药品销售任务、收款、处理购销票据，或统计医生个人处方数量 | 不把这些设成拜访训练目标或奖励指标，改用证据准确性、问题解决与资料跟进等指标 |
| 宣称所有患者有效、竞品更差，隐去已知风险，或把未获批用途说成可推广用途 | 收回超出证据和授权的结论，对照当前有效说明书及审核材料；医生主动问到超说明书问题时记录问题并转医学部门按流程答复，不引导使用 |
| 索要可识别患者资料或医疗机构内部资料 | 不指导非法收集使用；普通训练使用合成或充分去标识材料，真实报告通过有权限的专门渠道处理 |

对真实学术会议、咨询或患者教育项目，不仅凭名称认定合规或违规。核实真实目的、授权审批、适用制度、受益对象与资金安排，缺项交公司合规团队确认，不能虚构统一费用标准。

## 遇到疑似不良反应

不能为维持关系、等待因果确证或因信息不全而隐瞒、删除或拖延转交。按公司现行流程及时向药物警戒团队转交已知事实，标注未知项；补充信息与因果评价交由相应人员完成。不要在普通陪练、公开帖子或通用聊天中索取可识别的病例、联系方式、照片或病历；必要信息由授权渠道依法收集。不要编造“24小时”等统一法定期限，也不要把持有人对监管机构的报送期限当成代表可以等待的期限。

如描述正在发生的紧急危险，先建议由医疗机构及时救治，同时走药物警戒渠道；训练助手不作诊断、因果认定或患者停换药指令。

## 输出

简要指出原话/动作、风险及依据或不确定性，再给一个替代动作或说法。区分有证据的风险、待核实条件与一般沟通建议；保留引用，避免将“可能”改成确定法律结论。嵌入教练系统时使用原有字段，不新增评分或改变业务 JSON。
