# 医药代表循证沟通

先判断“这份材料支持怎样的结论”，再训练怎样说清楚。网上的培训文章只提供沟通方法，不提供产品疗效或安全性证据；病例分享、销售幻灯、指南摘要和原始研究不能互相冒充。

## 按问题核对证据

- 记录材料名称、出处、年份或版本、研究类型和审核状态；没有给到原文或审核信息，就说明可核对范围，不能声称已审核或已读全文。
- 把医生的问题对应到人群、干预、对照、结局及观察时间。按需核对入排标准、样本量、随机与盲法、失访及分析集；不要求一次口头回答背出全部术语。
- 分清主要终点与探索性终点、替代指标与患者重要结局。讨论效应估计、置信区间、安全性和外推局限，不能仅靠 P 值或论文结论词判定临床价值。
- 把“研究观察到”“学员声称”“模型计算”“尚缺资料”分开表述。亚组、观察性关联、间接比较不能自动升级成普遍适用、因果或优效结论；指南推荐也不自动等于某产品的获批适应症。

## 让数字不误导

对于相同结局、相同时点、可比人群的二分类不良事件，已知对照发生率 CER 与干预发生率 EER，且 CER > EER 时：ARR = CER − EER，RRR = ARR / CER，NNT = 1 / ARR；发生率用小数计算，获益 NNT 向上取整，说明相对谁、随访多久以及不确定性。方向相反时明确是风险增加，不称为获益。

区分百分比与百分点，同时给出绝对发生率和相对变化。RR是risk ratio（风险比），OR是odds ratio（比值比），HR是hazard ratio（瞬时危险比）；不要把HR叫作RR，也不能把HR的变化直接当成固定时点事件率下降，不能用“降低25%”推出ARR=25%或NNT=4。没有基线风险、时点或足够统计信息，就不计算绝对获益；时间事件分析不能把中位随访简单当成统一结局时点。两项研究没有直接比较或有效间接比较依据时，不能仅凭各自百分比宣布谁更好。

若需要课堂数字示例，见 [统计练习](references/practice.md)；这些数字是虚构教学材料，不属于任何药物的研究证据。公式的来源与适用限制见 [来源说明](references/sources.md)。

解释HR时保留“瞬时危险之比”，不要简化成RR或“随时间变化的相对风险”；是否可视为恒定比值取决于模型假设。计算得到的NNT说明随访时点、对照和向上取整，不能把算出的纠正答案误记为学员已经答对。

## 转成中文回应

先回应医生关切，再给支撑它的一条相关证据和关键局限，最后说需要补什么。缺数据时使用【待核实：主要终点】【待核实：安全性结果】等占位，不自行补入常见试验设计、剂量、入排标准或保证疗效。不同个体是否适用仍需临床判断与当前有效说明书。

辅导时指出原话里具体混淆了什么，再给保留事实的示例；原话有错误时明确更正，不把错误改得更有说服力。按调用方已有格式输出，真实引用与风险提示优先于文风润色。不请求患者身份资料，不给具体患者制定用药方案。
