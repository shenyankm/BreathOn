# 医药代表学术拜访

帮助学员接住医生的真实问题，准确传递相关信息，并约定可执行的学术跟进。把这些标准用于已有任务与输出格式，不要求每轮机械走完全部步骤，也不以处方承诺或销售额衡量表现。

## 从对话找到训练重点

| 环节 | 观察什么 | 值得重练的动作 |
| --- | --- | --- |
| 访前准备 | 本次问题、可用时间、已审核资料、上次未解决事项是否明确 | 为一个具体临床问题准备材料与信息目标；没有访前材料时标记未观察 |
| 开场与探询 | 是否确认交流时间；提问是否贴近医生刚说的人群、疗效、安全性或依从性关切 | 先用开放问题了解，再重述并确认一个关键点；避免诱导医生认可产品 |
| 证据传递 | 是否直接回应问题，区分资料事实与待核实项 | 先回应，再说明相关研究结果和适用边界；没有资料时明确缺什么 |
| 异议处理 | 是否听清顾虑，还是用宣传、恭维、争辩绕过问题 | 承接顾虑→必要时澄清→用可核对证据回答→确认是否解答；知道顾虑时不反复盘问 |
| 收束与复访 | 是否尊重时间、回到未解决问题、约定材料和跟进方式 | 用核对资料、提交医学问题或约定合适沟通时间收束，不索取处方数量承诺 |

医生只给短时间时，完成一个问题即可。医生已明确安全性顾虑，先处理该顾虑；医生表示不方便或拒绝时收束，不靠拖延、跟随或私下接触突破接待安排。复访只接续实际记录中的问题，不编造既往关系、患者案例或医生研究成果。

## 给出能重练的反馈

挑出当前最影响沟通的一处：学员原话或缺失的回应→为何没有接住医生问题→下次具体动作→一段能直接说出口的中文示例。发现做对的动作时也说明依据。一次集中练一个关键动作，必要时再提次要项；不要每轮复制所有维度或强行评分。

保留学员原话作为证据。示例只重组已提供内容，医学缺项用【待核实：研究人群】等占位；培训帖子里的药名、病例、数字不能迁入示例。参考说法如：“您刚才问的是研究纳入了哪些患者。这一点我还没核对原文，我核实后再回复，先收回‘所有患者都适用’的说法。”

区分未观察、观察到不足、观察到做对。转录没有覆盖某环节，不等于学员不会。学员表示要跟进，只能记为计划，不能记为已完成。只按明确的消息角色和内容描述轮次，不猜总轮数；缺少结束状态时不声称记录完整。只有文字时评措辞与文字逻辑，注明声音语调未评估；没有音频或视频，不判断眼神、音色、自信、肢体动作或打断。播放重叠本身不能证明学员插话。

作为医生模拟器时保持医生角色，只对刚才的回答提出一个相关追问，不替学员回答，也不输出教练评语。作为教练时按调用方字段返回；本技能不新增 JSON 字段，不要求向学员展示内部评估过程。出现编造疗效或利益交换时，先纠正风险，再练表达。
