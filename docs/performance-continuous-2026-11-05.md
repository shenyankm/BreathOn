# 持续性能优化验证 · 2026-11-05

基线 `514dcfa`。在同一台 macOS 27.0.1 / Apple Silicon 机器比较；本轮不增加运行时依赖或数据库迁移，测试数据与生产隔离。原始日志、JSON、截图保存在本机忽略目录 `backend/data/validation/perf-20261105/`，本文保留可提交的结果与复现入口。

## 保留的修改

按用户影响和证据优先处理以下问题，每项完成针对性验证后再执行完整回归：

| 问题 | 修复及边界 | 验证 |
| --- | --- | --- |
| 医生已生成仍等待教练，TTS 同时被阻塞 | 完整医生 JSON 和当前输入通过校验后发布并启动 TTS；教练稍后沿用消息 ID 补发 | 合成延迟对照、取消/修正/退出、拒绝无效输出、版本撤销、用量保留 |
| 资料和政策列表读取并解析所有正文后丢弃 | 数据库选择阶段移除 pages，详情仍保留全文 | SQLite/PostgreSQL 等价性、权限隔离、可用状态与全文读取回归 |
| 无有效医学判定也重复加载并计算资料凭证 | 仅在存在 supported/contradicted 判定时读取；有效判定继续逐次验证 | 空判定、处理中、无依据等状态零读取断言及撤销回归 |
| 政策目录依赖无关资料请求 | 仅药品目录请求关联资料 | 无关资料接口失败时政策仍可加载 |
| 医生备用插画体积过大 | PNG 改为无损 WebP，同时更新两个使用点 | 解码后 1254×1254 RGBA 字节及 SHA256 完全一致，浏览器确认可加载 |
| 200% 字体时医生编辑表单列过窄 | 按容器宽度切换布局，表单字段自适应换列 | 1024px/200% 字体输入宽度断言，多尺寸 CRUD 截图 |
| Android 验收脚本使用旧包名，撤销权限杀进程导致 CDP 失效 | 附加前重置权限、重启正确包、转发新进程并等待就绪 | 最终调试 APK 的原生权限拒绝、导航及账号偏好验收 |

语音保持原有 400ms 轮次去抖、调用限流、ASR/VAD 判断、PCM 格式、音质、播放校准和模型输出限制。没有绕过医学审批或账号隔离；医生不接收教练专用参考上下文，教练发布前仍校验自己的参考资料。修正和退出会取消未完成教练及语音；提前保存的医生用量不重复累加，未知用量保持不完整标记。

## 延迟对照

`backend/benchmarks/performance_continuous.py` 从 Git 加载基线模块。使用真实 PracticeDialogue、独立新建并关闭的 SDK 客户端、模拟 HTTP 医生 15ms/教练 100ms、模拟 TTS 首 PCM 20ms。预热导入及技能后交替执行，每版 20 次；逐次断言消息、教练和用量等价。

| 阶段 | 基线 p50 / p95 ms | 修改后 p50 / p95 ms |
| --- | ---: | ---: |
| 提交至后端发布首个有效医生文本 | 520.226 / 522.809 | 435.611 / 442.646 |
| 模型请求至后端发布医生文本 | 102.731 / 103.922 | 17.666 / 20.191 |
| 提交至后端首个 PCM 事件 | 542.064 / 545.192 | 457.552 / 464.977 |
| 整轮及语音任务完成 | 542.235 / 545.396 | 520.019 / 524.739 |

这些指标定位的是教练等待造成的本地排程延迟。供应商返回完整医生 JSON 的 p50 仍约 434ms（含 400ms 去抖）；没有加速模型自身。未测真实连接握手、ASR 停说至识别、原始首 token、界面首次绘制或首次可听播放，不能据此承诺线上端到端延迟。

## 数据库和启动对照

20 份合成资料，每份 50 万字符，临时表与同一连接交替读取，每版 20 次。小资料（每份 200 字符）作为控制组。未设置跨请求缓存。

| 数据库/场景 | 基线 p50 / p95 ms | 修改后 p50 / p95 ms |
| --- | ---: | ---: |
| SQLite，大资料列表 | 85.917 / 100.061 | 10.496 / 10.907 |
| PostgreSQL，大资料列表 | 117.525 / 119.089 | 34.313 / 35.154 |
| SQLite，小资料列表 | 0.036 / 0.042 | 0.027 / 0.035 |
| PostgreSQL，小资料列表 | 0.332 / 0.457 | 0.279 / 0.378 |

大资料列表 Python 临时分配峰值：SQLite 40,016,464 → 10,156 B；PostgreSQL 40,016,544 → 10,436 B。tracemalloc 不包含数据库/驱动原生内存、进程总内存或真实网络压力。

后端启动使用新 Python 进程、已预热文件系统和字节码、临时 SQLite/文件存储，停止模拟器和测试服务器后交替测量，每版 20 次：就绪 p50/p95 从 660.701/673.007ms 到 659.743/671.390ms，视为没有显著变化，不保留推测性的启动重构。

## 停止条件与剩余限制

已发现且可本地复现的高优先级问题完成修复和回归。其他候选暂不扩大实现：

- 原始 token 流式解析及分段语音需要真实供应商协议、输出完整性和真实听感验证；目前提前发布的是完整且已校验的医生回复。
- 未取得线上负载分布，不扩大缓存或连接池；字体已有按 Unicode 范围加载，删除多语言子集缺乏实际传输收益证据。
- Android 保留离线药品原始说明书，不通过删除医学来源缩减体积；大列表虚拟化和额外延迟加载没有稳定收益证据。
- 真机、弱网、真实供应商握手/ASR/TTS、物理麦克风及首次可听播放未验证；模拟测试不等于医学质量或上线验收。
- 基线提交的生产部署曾因 SSH 主机密钥不匹配失败（CI run 41997019853）；需要通过可信控制台独立核实指纹，未绕过检查或修改部署密钥。本轮推送后的 CI/生产结果需按新提交单独判断。
