# 7.2 通用评分维度

来源：用户提供的评分规则截图。

通用评分包含以下五个维度，**合计 100%**。评委将结合实际演示、提交材料和现场问答进行判断。

重点考察**技术完成度、创新性、场景应用价值、赛道契合度及 Demo 展示效果**。鼓励现场真实演示，强调 48 小时内的实际开发成果。

| 评分维度 | 建议权重 | 评审重点 |
|---|---|---|
| 技术完成度 | 30% | 核心功能、技术实现质量、产品可运行性 |
| 创新性 | 25% | 产品创意、技术应用及解决方案创新 |
| 场景与应用价值 | 25% | 需求真实性、解决问题的能力、落地潜力 |
| 赛道契合度 | 10% | 与赛道方向及命题要求的契合程度 |
| Demo 展示与表达 | 10% | 真实演示效果、表达逻辑、答辩表现 |
| **合计** | **100%** | |
