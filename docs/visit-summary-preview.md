# 拜访复盘评分卡原型

保持当前 UI 的黑白配色、圆角卡片及组件样式，展示医学准确性 40%、合规性 30%、沟通技巧 30%，加权总分以及最多三条“原话 → 问题 → 建议改法”。

```sh
npm --prefix frontend ci
npm run dev
```

打开 `http://127.0.0.1:5173/preview-visit.html` 查看示例；示例使用虚构成绩，不保存为训练记录。练习 / 实战切换和底部按钮用于展示交互，不会启动真实演练。

本分支保留了独立的评分后处理草稿：权重由程序固定；医学分数仅依据可核对的逐句判断，没有足够依据则不评分；合规与沟通分数必须引用学员实际原话。没有三条可改的原话时不补造。所有评分未经专家校准。

后端会保存 `summary_card` 并通过同名事件返回，但现有生产界面尚未接入该事件。正式替换复盘界面、专家校准和真实会话验收未完成，因此本变更保持 Draft 供设计评审，不作为已上线评分功能。
