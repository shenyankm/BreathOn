## 综合微基准

本机合成数据，5 组重复的中位数。新旧实现交替先后测量，先断言输出完全相同再计时；复盘只排除生成时刻字段。模拟存储不会联网或读取真实用户数据。耗时仅代表所列函数的局部 CPU 工作，不代表真实数据库往返、模型响应、设备帧率或线上端到端时延。

案例校验总耗时主要来自必须保留的完整资料哈希，约 5% 的差异接近本机波动范围；确定性收益是重复归一化次数降低，不能宣称消除了哈希成本。审批场景用于验证不合格票较多时的算法扩展性，不代表常规两票审批有 81 倍端到端收益。

归档选择阶段 tracemalloc 峰值 **528,024 → 886 B**，不包含已经存在的原文、分块列表或进程内存。减少的是选择过程的临时分配。

Web 登录入口 JS 309,340 B / gzip 100,759 B，Android 登录入口 JS 309,667 B / gzip 101,572 B；总体构建资源分别 3,922,911 B / 11,634,128 B，与本次基线一致，没有通过删除资料或降低画质改善指标。
