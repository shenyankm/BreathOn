# 当前功能范围

维护基线：2026-10-31。本文描述已接入的功能边界；发布状态以目标提交的 CI 和实际部署日志为准，历史测试数量不作为当前验收结论。

| 范围 | 当前行为 | 边界 |
| --- | --- | --- |
| 客户端与登录 | Android 用户端；Web `/admin` 管理后台；预配置账号、管理员角色与代表记录隔离 | 无公开注册；Web `/app` 已退出；无离线业务同步 |
| 医生与语音练习 | 医生 IP、辅助/实战、练习重点、转录与复盘 | 当前 App 教练以玛仕度肽自由练习启动，无评分场景选择器；真人听感需单独验收 |
| 训练与重练 | 场景、量表、资料版本、引用校验、专家校准、人工点评和同版本重练 | 自由练习无场景量表分数；未观察或无证据不填零分 |
| 学习课程 | L1–L4 课程维护、发布、个人计划、完成标记、实际进度与连续练习记录 | 不是旧企业课程分配、截止时间、考试次数或能力认证系统 |
| 管理后台 | 总览、药品、医生 IP、用户画像、政策、训练内容、审核队列、代表记录、系统设置 | 用户画像是目标人群内容设计；指标为工作区真实汇总，不冒充个人健康档案或画像子群统计 |
| 发布治理 | 内容版本、管理员/双人/医学与合规审核、工作区推荐及评分开关 | 审核绑定内容与设置版本；不同审核职责仍需不同管理员 |
| 资料研究 | 医生与药品公开来源检索、归档、草稿、人工确认及可选追踪 | 不自动发布，不推断真人私有偏好；真实调用可能收费 |
| 拜访与案例 | 个人日记、录音转写、人工核对脱敏、管理员审核与案例复用 | 原音频与未脱敏文本私有且有保留期限 |
| 健康观察 | 手动保存、逐条授权、管理员审核、代表端共享与撤回 | 默认私有/关闭共享；未接项链或设备，无诊断或疗效推断 |

没有恢复培训证书、排行榜、考核成绩审批、正式申诉、成员自助管理或企业系统对接。内容发布审核不等于考核成绩审批；L1–L4 学习进度不等于认证。历史实体与会话不通过清理文档删除，旧课程启动参数仍被拒绝。

操作见[使用手册](user-manual.md)和[管理后台说明](admin-management.md)，实现与访问边界见[架构](architecture.md)，验收证据与早期精简过程见[文档索引](README.md)。
