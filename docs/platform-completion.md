# 当前功能与验收

产品主线：选择医生与场景 → 演练 → 按原话和资料复盘 → 针对性重练。根据用户的精简要求，撤回此前把原型扩展为企业培训平台的旁支。

| 保留 | 目的 |
| --- | --- |
| 练习/实战语音、真实DeepSeek与按场景加载skills | 医生交流与统一指导 |
| 医生库、场景与分阶段演练 | 控制对象、问题和目标 |
| 审核资料、版本、原文/PDF/本地导入 | 给医学判断提供可核对依据 |
| 量表锚点、引用校验、专家校准 | 明确评分依据与不确定性 |
| 原话与复盘记录、点评与留痕改分 | 解释反馈并保留原始评价 |
| 同版本重练、原记录关联、维度对比 | 形成练习闭环 |
| AI 场景草稿、来源版本与生成记录 | 从资料生成可核对的新训练素材 |
| 经验案例、场景模板导出导入 | 通过文件传播可复用的沟通素材 |
| 个人同条件反馈、用量与计价快照 | 查看练习记录与已报告服务成本 |
| 单用户本机使用、资料审核留痕 | 简化使用流程并保留资料版本和依据 |

## 已删除

- 课程编排、任务分配、截止时间及考核尝试次数。
- 培训认证、补考、签发/撤销及成绩审批。
- 每日目标、连续天数、徽章与排行榜。
- 企业运营看板与团队趋势统计；本轮增加的个人同条件反馈不包含团队运营功能。
- 独立资料助手及其收费生成流程。
- 正式申诉与学员回应提交流程（历史文字保留可读）。
- 注册、登录、成员管理和角色/团队隔离。

对应后端路由、数据模型、业务模块、前端页面、表单与失效测试均已清理，不只是隐藏入口。第15项企业系统对接继续不接。

## 数据与兼容

没有删除已有会话、资料、课程元数据或证书历史数据。旧记录包括匿名记录可查看；平台资料沿用首次初始化的工作区，其他工作区不自动合并。移除的实体不再通过接口提供新建和操作。旧课程启动链接明确报错，不能绕过为普通演练。

## 修复

原重练入口漏传重练标识，只有场景信息，导致新演练不能关联原记录。现在共享启动接口返回标识，记录页直接启动；后端重新校验归属和状态，锁定场景/环节并保存关联。新增回归覆盖启动路径、维度关注点、完成状态、跨模型不比较以及接口删除后的数据保留。

## 验证

2026-10-29 本轮交付完成核心训练闭环及 P1：场景生成、四类情境与难度、原话复盘重练、案例复用、个人反馈与成本记录、轻量模板分享。P2 明确不实现。当前代码的测试、真实服务输入边界、原始结果及复现步骤统一见 [训练闭环交付与验收](training-delivery.md)。以下保留旧版本精简时的历史记录。

验证结果在本轮精简后重新记录；此前128项测试与旁支助手的真实模型结果属于历史版本，不能作为当前版本的完整验收结论。医学评分与语音生成主路径未更换；保留此前指导模型的合成输入证据，真实专家校准与真人麦克风听感仍未完成。


以下为此前版本精简后的历史验证，不代表单用户改造的验收结果：

- 后端全量 **123项通过**，包含真实临时PostgreSQL与SQLite；课程等旁支测试已删除，替换为接口退出、历史数据保留和重练闭环回归。
- 前端 **6项通过**，生产构建通过；lint仅保留原有3条UI组件Fast Refresh提示。
- 浏览器确认管理员配置导航从11项缩到6项，学员只见4项；记录页直接显示待重练，点击后锁定原场景和环节。
- 1440、768、390宽度实际检查，记录列表和重练卡片可用，手机标题与状态换行已调整。截图位于`.taste-skill/inspect-slim/records-{desktop,tablet,mobile}.png`，均为隔离工作区的合成测试资料。
- 源码净减少约600行，未执行历史数据删除或数据库降级。主后端已重启，前端开发服务已启动。
