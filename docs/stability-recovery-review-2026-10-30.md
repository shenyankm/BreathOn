## 修复

| 链路 | 故障与处理 |
| --- | --- |
| 会话保存与关闭 | 保存线程运行时重复取消不会提前释放会话容量，数据库失败后的私有恢复副本也会等待写完；复盘错误通知期间取消仍保留原话。应用关闭先停止准入、取消并排空已接纳的会话，再关闭存储，覆盖 Uvicorn 超过优雅关闭时限后直接进入 lifespan 的行为。 |
| 研究任务 | 创建、取消收尾、最终落盘和关闭恢复中的数据库线程均等待完成后才传播取消或释放生命周期锁。重复取消不会留下未登记但仍写入的线程。 |
| 校准任务 | 中间进度写入复用最终结果写入的取消等待逻辑，先完成进度事务，再保存中断状态。 |
| 语音清理 | 练习模式所有客户端发送设置 5 秒期限；慢客户端无法无限阻塞朗读取消。分阶段清理用 `finally` 保证继续停止朗读、客户端接收与 ASR 接收任务。 |
| 模型用量 | 模型返回后立即保存已返回的用量；后续资料校验失败或转录修正导致回复作废，不再丢失这次调用的用量。 |
| 历史记录 | JSON 与 PostgreSQL 聚合逐条隔离结构损坏的记录。损坏的派生 activity 缓存从原记录重算并校验；PG 正常缓存保持轻量查询，只有坏缓存补读原记录。原始数据不改写。 |
| 本地文件 | 列表跳过、导入拒绝 FIFO 等非普通文件，避免读取永久阻塞；文件检查后被删除时按缺失处理，批量读取保留其他记录。 |
| 原件完整性 | 研究归档读取验证原件实际 SHA-256；平台 PDF 下载校验 Base64、大小和哈希。损坏原件明确报错并保留文件，恢复正确副本后可再次读取。 |
| API 校验错误 | Catalog 创建和编辑统一使用有界脱敏校验响应，避免回显超长未知字段名及无界错误列表。 |
| 历史费用 | 损坏的用量/价格结构、非有限或负数金额、非法计价单位数量均标记该次费用不可核算，其他会话继续统计。安全响应不含会使页面崩溃的坏用量；未知费用不按零计算。 |
| 前端保存与并发读取 | 保存成功后直接采用返回的新版本，避免额外列表请求失败导致误报或旧版本重试。并发列表读取按修改的 ID 合并：保留本地新版本、合并无冲突历史项，旧响应不能复活已删除医生。 |
| 浏览器音频 | 播放调度失败时立即断开失败节点，只有成功启动的节点进入播放集合，避免错误恢复再次停止未启动节点，进而中断麦克风与 AudioContext 清理。 |
