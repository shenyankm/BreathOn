# Agent 可靠性、可观测性与评分校准

本文记录教练、医生、研究与评分卡 agent 的生产化约定。代码在 `backend/medvisit/agents/`。

## 失败如何处理

- **一次重试**：每次模型调用遇到可恢复错误（408、429、5xx、连接错误）时，在共享并发闸门内重试一次，间隔 0.5 秒。客户端超时不重试，避免超出一轮的总时限。401、400 等永久错误不重试。
- **教练与医生解耦**：实时轮次中，教练失败或超时只会让教练面板降级（`coach.degraded` 记录失败原因，内容为诚实的占位说明，不编造分析），医生回复照常送达。医生失败仍使整轮失败。整场复盘没有可降级的内容，教练失败即整体失败。
- **长度超限不再整轮失败**：教练文字超过上限时截断并加省略号；结构错误（缺字段、空文本、建议数量不在 1 至 4）仍然拒绝。校验在 `outputs.py` 用 pydantic 统一实现。
- **不放宽证据校验**：评分的原话与资料引用、研究的来源域名与逐字引文规则没有变化。

## 观测

`GET /api/admin/agent-metrics`（仅管理员）返回当前进程的计数器：

| 前缀 | 含义 |
| --- | --- |
| `ok.practice_turn` / `ok.review` | 成功的实时轮次 / 复盘 |
| `failed.<用途>.<原因>` | 失败次数；原因为 `timeout`、`rate_limited`、`provider_error`、`invalid_output`、`service_error` |
| `failed.coach_degraded.*` | 教练降级但医生仍送达 |
| `retry.*` | 触发重试的次数 |
| `quotes.removed` | 被替换掉的无法核对的引文数 |
| `assessment.validation_failed` | 评分引用未通过校验 |
| `routing.*` | 各技能路由命中；`routing.none` 占比升高说明有漏判措辞 |
| `search_blocked.*` | 被隐私过滤拦下的搜索词，按类型计数 |
| `failed.research.*` | 检索任务失败原因 |

计数器按进程统计，重启清零；多进程部署需要自行汇总，指标不含任何转写、查询或个人信息。

## 评测

- `tests/live_coaching.py --live` 调用真实模型（付费），覆盖 18 个场景，其中新增提示注入、医生拒绝后收束、超说明书、超长输入。
- `tests/agent_eval.py <报告>` 离线打分，通过率低于 `REGRESSION_FLOOR`（85%）时退出码为 1，可作为改提示词或换模型前的回归门。
- `tests/fixtures/coaching-golden.json` 保存已通过检查的录制输出，CI 中离线验证检查规则与输出结构没有漂移。它不调用模型，不能替代真实模型复测。

## 评分校准

校准指标除 MAE 和“相差一分以内”外，增加二次加权 kappa、偏差方向和运行间稳定性。kappa 与稳定性在能计算时低于门槛（0.6 与 0.9）会阻止标为“已校准”；样本太少算不出时只报告，不放行也不否决，仍由样本数和 MAE 把关。

`CALIBRATION_REPEATS` 默认为 0。要测稳定性，设为 1 至 3，每个样本会多付对应次数的模型调用。

资料适用性复核可通过 `DEEPSEEK_REVIEW_MODEL` 使用不同模型。评估结果的 `review_model` 记录实际使用的模型；`calibrated_model` 仍对应评分模型。

## 隐私

搜索词先经 `query_guard.py` 检查：手机号、身份证号、邮箱、病历/住院号/床号、“患者+姓氏”和“性别+年龄”会被拒绝，不发往搜索服务。这是筛查而不是保证，不能识别所有姓名或自由文本病例描述，提示词约束和 128 字限制仍是另外两层。

## 仍需人工决定的事项（代码无法解决）

- 用真实在世医生的公开信息建模训练角色，建议在商用前做法务评估或取得授权。现有免责声明与第三人称约束已在提示词中，但不等于授权。
- 学员原话会发送给 DeepSeek；上线前需确认数据处理协议、保留期限和境内外传输要求。
- 评分用于考核、晋升或认证前，需要足量专家标注并通过上述校准；当前所有量表默认 `uncalibrated`。
- 医学分数按“被支持断言占比”等权计算，代码中已标注为 shortcut，缺少严重度加权。
