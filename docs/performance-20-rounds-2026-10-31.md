## 逐轮记录

每轮先定位重复工作或入口依赖，再做小范围修改并运行相关测试或构建；最终统一做完整回归。轮次表示优化步骤，不代表 20 个独立提交。调用次数与分配量是确定性指标，耗时是最后一组综合对照测量。

| 轮次 | 修改 | 验收与收益 |
| --- | --- | --- |
| 1 | Web 应用在认证后异步加载 | Web 构建通过；登录入口不再直接加载整个管理应用；增加加载状态 |
| 2 | Android 应用在认证后异步加载 | Android 构建通过；登录时不加载语音演练与工作台代码 |
| 3 | 管理页分区异步加载 | 总览、医生、画像、课程、审核、记录、设置按需加载；浏览器逐页验证 |
| 4 | Android 次级页面异步加载 | 训练、课程、医生、教练、我的分包；加载时保留底部导航；首页/训练/教练/我的浏览器验证 |
| 5 | 空目录搜索绕过 JSON 序列化 | 空搜索的行序列化次数由 N 次变为 0 次；非空查询结果测试通过 |
| 6 | 复用未变化的目录筛选结果 | 编辑表单、加载状态改变时不重新序列化列表；查询改变时仍更新结果 |
| 7 | 分类选项仅在目录变化时重建 | 五组去重与中文排序不再随表单操作重复执行；构建及目录回归通过 |
| 8 | 总览时间戳只解析一次 | 100 条更新时间仅解析 100 次；排序、无效日期过滤与同分顺序保留 |
| 9 | 课程查找命中即返回 | 不再展开整个课程数组；测试验证首项命中不访问后续课程，并覆盖未命中 |
| 10 | 无引文时跳过转录归一化 | 无引文的教练反馈与单文本校验均不读取/归一化整段转录 |
| 11 | 多字段引文检查共享本次转录归一化结果 | 同次反馈由每字段一次降至最多一次；保留引用替换与不校验示例话术的规则 |
| 12 | 同次合规检查复用政策读取 | 1000 条同政策规则的读取次数由 1000 降为 1；下次请求仍重新读取并发现停用 |
| 13 | 收集 20 条有效规则后停止 | 保持原有 20 条上限与顺序；无效版本仍先排除，不继续验证不会返回的尾部规则 |
| 14 | 空发言直接跳过合规存储访问 | 空白输入不进入线程池、不打开事务；返回原有 skipped 状态 |
| 15 | 审核文档页只归一化一次 | 10 个同源引用由 20 次页归一化降至 11 次；审核撤销仍立即生效 |
| 16 | 按来源 URL 分组审核凭据 | 避免来源 × 全部文档的嵌套匹配；只归一化存在匹配来源的文档，避免新增无用工作 |
| 17 | 编译事实文本只归一化一次 | 从每查询词一次降至每事实一次；匹配阈值保持不变 |
| 18 | 检索查询不变量移出分块循环 | 年份、问题类别、产品集合、词权重只计算一次；对照断言检索结果一致 |
| 19 | 同次检索复用来源匹配结果 | 40 个同源块只提取一次试验名称；逐块评分顺序、同分顺序和页数上限保持不变 |
| 20 | 顺序迭代原始块与派生块 | 用 `chain` 避免额外复制整个分块引用列表；结果与原版一致 |

## 测量结果

入口 JS 包含 HTML 入口、modulepreload 及递归静态 import，排除尚未访问的动态模块。不是只比较主 JS 文件。gzip 使用 Node 默认设置逐文件计算。

| 指标 | 基线 | 20 轮优化后 | 包含新版登录页的最终构建 |
| --- | ---: | ---: | ---: |
| Web 登录入口 JS | 512,995 B | 307,514 B | 309,340 B |
| Android 登录入口 JS | 548,849 B | 307,813 B | 309,667 B |
| Web 登录入口 gzip | 155,332 B | 100,075 B | 100,759 B |
| Android 登录入口 gzip | 174,978 B | 100,937 B | 101,572 B |
| Web 全部构建资源 | 3,915,531 B | 3,921,085 B | 3,922,911 B |
| Android 全部构建资源 | 11,624,064 B | 11,630,168 B | 11,634,128 B |

最终入口 JS 减少约 40% / 44%。分包包装与登录页样式使完整构建增加约 7.4 KB / 10.1 KB，不能据此宣称 APK 变小。图片与 PDF 保持原件，未通过降低画质或删除资料制造体积收益。

以下为本机合成数据、5 次重复的中位数，每次调用耗时；不代表远端模型时延、真实设备帧率或线上端到端响应时间。

| 合成场景 | 基线 | 优化后 | 倍率 |
| --- | ---: | ---: | ---: |
| 100 轮长转录、多字段引文核验 | 6.134 ms | 0.696 ms | 8.81× |
| 1000 条同政策规则，返回 20 条 | 0.566 ms | 0.012 ms | 48.25× |
| 30 个来源、80 个审核文档的凭据匹配 | 44.826 ms | 29.884 ms | 1.50× |
| 含审核文档的完整检索 | 158.148 ms | 140.190 ms | 1.13× |
| 1200 块检索，单独测检索计算 | 28.902 ms | 26.148 ms | 1.11× |

对照脚本先断言新旧实现输出一致，再计时；额外覆盖未知查询、药品剂量、政策年份和试验名称。审核数据仅在一次调用内复用，没有跨请求医学审批缓存。

## 登录页追加需求

按用户第二张参考图实现 Android 登录页：浅绿至青色渐变、几何线条、球体、淡紫胶囊输入框、黑色圆角按钮，文案为“你好”“欢迎来到灵息BREATHON”“登录”。没有“/注册”、公开注册流程或无目的地的协议链接。

保留账号密码、显示/隐藏密码、密码管理器自动填充、失败重试、忙碌状态与原认证逻辑。图案使用内联 SVG 和 CSS，不新增位图。输入框高 62px、提交按钮高 60px、密码切换触控区域 48px；可见字段标签、焦点轮廓及安全区间距保留。Web 管理登录页维持原布局。
